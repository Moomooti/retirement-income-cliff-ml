1. 입력 단계 (네 기둥 재구성)
────────────────────────────────────────
[첫째 기둥 · 年 – 나와 가족]
  유지  출생연도
  유지  배우자 (있음 / 없음)
  추가  성별 (남 / 여)
  추가  학력 (고졸 미만 / 고졸 / 대졸 이상)
  추가  함께 사는 가구원 수, 본인 포함: 지금 ○명 / 2년 전 ○명  (1~10)
  이동  예상 은퇴 나이 → 9번 '선택: 은퇴 계획' 묶음으로

[둘째 기둥 · 月 – 연금 곳간]
  추가  국민·공무원·사학연금을 지금 받고 있나 (예 / 아니오)
  추가  퇴직연금 가입 (예 / 아니오)
  추가  개인연금 가입 (예 / 아니오)
  이동  국민연금 월 예상액·개시 나이, 퇴직·개인연금 월 환산액 → 9번 묶음으로
        (국민연금공단 조회 버튼도 같이 이동)

[셋째 기둥 · 日 – 소득의 흐름]
  유지  가구 한 달 실수령 소득: 지금 / 1년 전 / 2년 전
  문구  라벨을 "가구 전체 한 달 실수령 소득(세금·보험료 뗀 금액)"으로
  이동  소득 구성 슬라이더 → 9번 묶음으로 (모델 입력 아님)

[넷째 기둥 · 時 – 일과 재산]
  추가  지금 일하고 있나 (예 / 아니오)
  추가  1년 전에 일하고 있었나 (예 / 아니오)
  추가  2년 전에 일하고 있었나 (예 / 아니오)
  추가  일의 형태 (상용직 / 임시·일용직 / 자영업 / 그 밖의 일 / 일 안 함)
        - "지금 일함 = 아니오"면 자동으로 '일 안 함' 선택
  추가  사는 집 (자가 / 자가 아님)
  추가  금융자산 (예금·적금·주식·채권·계, 만원)
  추가  부동산 – 문구 정확히: "소유한 집·건물·토지 시세 합계 (자가면 사는 집 포함, 전세보증금은 넣지 마세요)"
  추가  부채 – 문구 정확히: "남은 빚 잔액 (한 달 상환액이 아니에요)"
  이동  한 달 부채 상환액, 은퇴 후 일 계획·예상 월수입 → 9번 묶음으로

[선택 · 건강]
  추가  건강 상태 (매우 좋음 ~ 매우 나쁨 5단계 / 말하고 싶지 않음 = 기본값)
        - 기본은 보내지 않음. 모델 검증에서 건강을 넣어도 성능 차이가 없었음(손실 +0.0001).

[9. 선택 – 은퇴 계획까지 보기] (접힌 상태로 마지막 단계 아래)
  은퇴 나이, 국민연금 월 예상액·개시 나이, 퇴직·개인연금 월 환산액, 소득 구성,
  한 달 부채 상환액, 은퇴 후 일 계획·월수입
  - 이 값들은 모델에 보내지 않고 '단순 계산' 카드(공백기·은퇴 후 월수입·빚 부담)에만 씀.
  - 비워 두면 해당 계산 카드는 숨김.

2. 입력 검사 (validate)
────────────────────────────────────────
  - 필수: 출생연도, 성별, 배우자, 학력, 가구원 수(지금·2년 전), 연금 3종, 소득 3칸, 일함 3개, 일의 형태, 자가, 금융자산, 부동산, 부채

  - 오류 문구는 지금처럼 아기씨 말투 유지

4. 결과 화면 – 머신러닝 카드 ("2년 뒤 노후 운")
────────────────────────────────────────
응답 필드: eligible, reason, band, top_pct, abstain, reasons[{label, effect}], ratio_now, model

  상태 ① API_BASE 비어 있음 → 지금처럼 "준비 중"
  상태 ② eligible = false → reason 그대로 표시 + 아기씨 한마디
        (예: 50~69세가 아님 / 지금 소득이 빈곤선 아래 → 제도 상담 안내)
  상태 ③ abstain = true (시험셋 약 28%) → 순위 숫자 대신
        "아기씨도 이번 점괘는 한쪽으로 단정하지 못했다" + 이유 3개만 표시
  상태 ④ 정상 결과
        - 구간 이름(겁주지 않는 말): high "살필 운" / mid "다듬을 운" / low "평안한 운"
        - "같은 나이대 100명 중 위험 순위 상위 ○%" (top_pct 반올림)
        - 이유 3개: label + 방향(effect > 0 "위험을 올림", < 0 "위험을 낮춤"), 막대 길이 = |effect|
        - 지금 소득은 빈곤선의 ○배 (ratio_now, 소수 1자리)
  공통 각주: "예측일 뿐 미래를 보장하지 않아요. '살필 운' 100명 중 실제로 2년 뒤 반복해서 빈곤선 아래로 간 사람은 약 22명이었어요(복지패널 시험)."
  로딩: 지금 챗봇처럼 6초 넘으면 "서버를 깨우는 중(최대 1분)" 문구

  아기씨 한마디(oracle): 9번 선택 묶음을 안 채웠으면 단순 계산 대신 ML 결과 기준으로
    high → "흐름이 꺾이기 전에 미리 보았으니 바꿀 길도 있다. 이유 세 가지부터 살펴보거라."
    mid  → "크게 흔들리진 않으나 다듬을 곳이 있구나."
    low  → "지금 흐름은 평안하다. 그래도 해마다 한 번은 다시 짚어 보거라."
    abstain → "이번 점괘는 아기씨도 단정하지 않겠다. 대신 이유를 함께 보자."
