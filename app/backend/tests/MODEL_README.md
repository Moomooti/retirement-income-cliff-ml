# 미리사주 서비스 모델 패키지

미리사주 화면 21문항을 그대로 받아 2년 뒤 소득절벽 위험을 계산한다. 사전 등록(prereg_S.txt) 기준을 통과한 모델이다.

## 검증 결과 (복지패널, 봉인 시험 2020·2021년 조사, 4,984행)
| | 건강 제외 S20 (기본) | 건강 포함 S21 |
|---|---|---|
| 서비스 모델 AUC | 0.868 | 0.869 |
| 전체 입력 모델(보고서 v3) AUC | 0.870 | 0.870 |
| 손실 (사람 단위 부트스트랩 95%) | +0.0012 [-0.0032, +0.0061] | +0.0001 [-0.0041, +0.0045] |
| 지금 소득만 대비 (DeLong 하한) | +0.057 (+0.043) | +0.058 (+0.044) |
| 판단 보류 포함률 (하락자 / 비하락자) | 89.7% / 92.9% | 90.0% / 92.4% |

기준(손실 점추정 ≤ 0.01, 상한 ≤ 0.02 · 지금 소득 대비 하한 > 0 · 포함률 ≥ 88%) 모두 통과.
회상 소득 민감도: 1년·2년 전 소득에 ±20% 잡음 → AUC −0.0009, ±40% → −0.0037 (허용 기준 0.01 이내).
화면 경로 검증: 시험 행을 화면 입력으로 되돌려 넣은 점수와 학습 점수의 상관 0.9995, AUC 0.8684 → 0.8678.

## 입력 규칙 (화면 문구와 맞출 것)
- 소득: 가구 전체 한 달 실수령(세후), 만원. 지금 / 1년 전 / 2년 전.
- 부동산: 소유한 집·건물·토지 시세 합계 (자가면 사는 집 포함, 전세보증금은 넣지 않음). 학습 데이터 정의와 같다.
- 금융자산: 예금·적금·주식·채권·계 등. 부채: 남은 빚 잔액(월 상환액 아님).
- job_type: regular 상용 · temp 임시·일용 · self 자영업 · other 그 밖의 일 · none 일 안 함.
- health(선택): 1 매우 건강 ~ 5 매우 나쁨. 없으면 건강 제외 모델.

## 계산 방식
- 소득 → 빈곤선 대비: 월×12 → CPI로 2023년 가격 → ÷√가구원 수 → ÷그해 가처분 빈곤선.
  '지금' 소득은 2025년 소득으로 본다(default_income_year). 2025년 빈곤선은 2024년 값과 실질 같다고 가정, 2026년 물가는 2025년 CPI로 근사.
- 1년 전 소득의 가구원 수는 지금 가구원 수로 근사한다(화면에서 묻지 않음).
- 대상: 50~69세이고 지금 소득이 빈곤선 이상인 사람만 점수를 낸다. 아니면 eligible=false와 이유를 돌려준다.
- 점수: LightGBM·로지스틱 점수를 시험 기간 분위수로 바꿔 평균 → 위에서 몇 %(top_pct). band: high ≤ 20%, mid ≤ 40%, low 그 밖.
- 판단 보류(abstain): 클래스별 분할 컨포멀(α=0.10)에서 위험·안전 둘 다 가능할 때 true. 시험셋의 약 28%가 해당.
- 이유: LightGBM TreeSHAP 기여 절댓값 상위 3개. effect > 0이면 위험을 올림.

## 주의
- parity_cases.csv는 합성 데이터다. 패널 약관·팀 규칙상 실제 개인 단위 값은 넣지 않았다.
- 패널 자료로 학습한 모델이다. 공개·영리 서비스 사용은 각 패널 기관 확인 전이다(보사연 약관: 사전 승낙 없는 영리 이용 금지).
- 예측일 뿐 미래를 보장하지 않는다. 위험 구간에도 실제로는 괜찮은 사람이 섞여 있다(상위 20%의 실제 하락률은 약 20%대).
