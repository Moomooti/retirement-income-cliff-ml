# data

이 폴더는 비어 있어요. **패널 원자료는 이용약관상 재배포가 금지**돼 있어서 저장소에 올리지 않았어요.

코드를 다시 돌리려면 각 기관에서 승인받은 원자료를 받아 `raw/` 아래에 두세요 (경로는 `src/01_panel_conversion/b_*.py` 참고).

| 패널 | 기관 | 역할 |
|---|---|---|
| 한국복지패널 (KOWEPS) | 한국보건사회연구원 · 서울대 | 판정 · 서비스 모델 학습 |
| 재정패널 (NaSTaB) | 한국조세재정연구원 | 판정 |
| 국민노후보장패널 (KReIS) | 국민연금연구원 | 판정 |
| 한국노동패널 (KLIPS) | 한국노동연구원 | 재현 · 이식 |
| 한국의료패널 (KHP) | 한국보건사회연구원 · 국민건강보험공단 | 재현 · 이식 |
| 고령화연구패널 (KLoSA) | 한국고용정보원 | 재현 · 이식 |

> 집계 수치(개인 단위 값 없음)는 `results/`에 있어요.
