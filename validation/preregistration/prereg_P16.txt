사전 등록 – ML 프로세스 점검 실험 P1~P6 (2026-11-04, 실행 전 고정)
대상 과제: KOWEPS_r, NaSTaB_r, KReIS_r (판정 3개, 가처분), KReIS_rn, KLIPS_r (보조)
봉인 시험셋·입력·정답은 v3와 동일. 기준 모델 = v3 LightGBM(사전 지정), 최종 = LightGBM+로지스틱 순위 평균.
판정용 차이 = 과제별 DeLong 차이 → 3개 판정 과제 랜덤효과 메타(DerSimonian–Laird).

P1 하이퍼파라미터 탐색 확장
  Optuna TPE 60회. 탐색은 학습 앞부분(it) 학습 → 내부 검증(iv) AUC로만. 시험셋은 보지 않음.
  공간: num_leaves 7~127, min_child_samples 10~400, learning_rate 0.01~0.1(log), feature_fraction 0.4~1,
        bagging_fraction 0.5~1, lambda_l1·lambda_l2 1e-3~10(log), min_split_gain 0~1. 조기 종료 100.
  판정 "튜닝 이득": (튜닝 LightGBM − v3 LightGBM) 메타 95% 하한 > 0. 아니면 "튜닝 부족 아님".

P2 클래스 불균형 처리
  (a) scale_pos_weight = 음성/양성, (b) 음성 무작위 언더샘플링 1:1. 나머지 설정은 v3 LightGBM과 동일.
  지표: AUC, 상위 20% 재현율, Brier, ECE(10구간).
  판정 "채택": 어느 방식이든 (방식 − v3) AUC 메타 하한 > 0. 아니면 불채택(보정 악화 폭 함께 보고).

P3 스태킹
  기본 모델 4개(LightGBM, XGBoost, CatBoost, 로지스틱 L2; v3 설정 그대로)의 학습셋 OOF 예측(사람 단위 GroupKFold 5)으로
  상위 로지스틱 모델 학습(입력 = 각 예측의 로짓). 시험셋은 v3 전체 학습 모델 예측에 적용.
  판정 "채택": (스태킹 − v3 최종) 메타 하한 > 0. 아니면 순위 평균 유지.

P4 결측 처리 비교
  (a) LightGBM 기본 결측 처리(v3), (b) 중앙값 대체 + 결측 표시, (c) 반복 대체(IterativeImputer, 5회) + 결측 표시.
  판정: (b)/(c) − (a) 메타 하한 > 0이면 교체, 아니면 v3 유지.

P5 평가 지표 확장 (새 학습 없음)
  PR-AUC(평균 정밀도), 상위 20% 정밀도·재현율·리프트, 의사결정 곡선(순이득, 임계 확률 0.05~0.40).
  확률이 필요한 곡선은 LightGBM 확률 vs 계산기형(B1) 확률 vs 전원 경보 vs 무경보.
  판정 A: 최종 모델 PR-AUC > 지금 소득, 5개 과제 모두 + 판정 3개 과제 사람 단위 부트스트랩(1,000회) 하한 > 0.
  판정 B: 임계 확률 0.10~0.30 구간 평균 순이득이 LightGBM > max(B1, 전원 경보) 인 과제가 4/5 이상.

P6 배포 실측 (복지패널 LightGBM, 2 CPU)
  1명 예측 지연(중앙값, 1,000회), 1명 예측 + 개인별 기여도(TreeSHAP) 지연, 10만 명 배치 시간, 모델 파일 크기.
  판정: 1명 예측+기여도 < 50ms 이고 10만 명 배치 < 60초 → "실시간 진단 + 야간 배치 모두 가능".
