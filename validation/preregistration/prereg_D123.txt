사전 등록 – D1 인과 ML · D2 공정성 · D3 운영 시뮬레이션 (작성 2026-11-04 10:09 KST, 실행 전)
공통: v3 데이터(복지·재정·국민노후(가처분)·노동). 결과와 무관하게 모두 보고.

[D1] 재취업 효과 – 이중 강건 추정(AIPW, 교차 적합)
- 대상: t 시점 50~69세 미취업자이며 v3 정답(1~4년 뒤 3번 중 2번 빈곤선 미만)이 관측된 행(학습+시험 전체). t 시점 소득이 빈곤선 이상인 v3 대상.
- 처치 A = t+2 조사에서 취업. 결과 Y = v3 지속 하락. 공변량 = v3 입력 중 t 시점 이전 정보(취업 관련 t 시점 변수는 상수라 제외되지 않음).
- 방법: 성향 e(X)=P(A=1|X), 결과 모형 μ_a(X)를 LightGBM으로 사람 단위 5겹 교차 적합. AIPW로 평균 처치효과(ATE). 성향 0.02~0.98 밖은 제외(겹침). 표준오차는 영향함수 기반 + 사람 군집.
- 위약 검정: 같은 방법으로 '미래 재취업'이 t 시점 이전 결과(t−2 대비 t 시점 빈곤선 미만 여부… 대상이 t 시점 빈곤선 이상이므로 대신 t−2 시점 빈곤선 미만 여부)를 '설명'하는지 추정. 효과가 0과 구별되지 않아야 함.
- 판정: '인과 근거 있음' = 4개 패널 결합(역분산) ATE의 95% CI 상한 < 0 이고 위약 효과의 95% CI가 0을 포함. 그 외 = '인과 근거 불충분'.
- 함께 보고: 단순 차이, 위험 10분위 층화 차이(M7), AIPW.

[D2] 공정성 – 운영 기준(시험셋 상위 20% 경보)에서의 집단별 미탐·오탐
- 모델: v3 최종(LightGBM+로지스틱) vs 지금 소득. 경보 = 각 방식의 시험셋 상위 20%.
- 집단: 성별, 학력(3), 나이(50대/60대), 1인/2인 이상 가구, 취업/미취업.
- 지표: 미탐률(하락자 중 경보 못 받은 비율), 오탐률(비하락자 중 경보 받은 비율), 집단 간 최대 차이.
- 판정: '악화 없음' = 4개 패널 중 3개 이상에서 최종 모델의 집단 간 최대 미탐률 차이가 지금 소득 기준의 차이보다 크지 않음(+2%p 이내 허용). 그리고 모든 집단에서 최종 모델의 미탐률이 지금 소득보다 낮거나 같음(+2%p 허용)인 비율 보고.

[D3] 운영 시뮬레이션 – 고정 vs 재학습, 분포 변화 경보
- 패널: 복지 · 노동(매년 조사, 기간 김). 기준 차수마다 '그 시점까지 결과가 관측된 자료로 학습한 모델'을 가정.
- 고정 모델: 가장 이른 학습 시점(복지 ≤2010, 노동 ≤2009 결과 종료분)으로 한 번 학습. 재학습 모델: 각 평가 연도 직전까지 결과가 관측된 자료로 매년 재학습. 평가: 이후 각 기준연도별 AUC.
- 분포 변화: 각 평가 연도 입력의 PSI(학습 자료 대비, 상위 10개 중요 변수 평균).
- 판정: '재학습 이득' = 평가 연도 평균 AUC 차이(재학습 − 고정) > 0 이고 연도별 부호가 과반에서 양수. '경보 유효' = 연도별 PSI와 고정 모델 AUC 하락 폭의 스피어만 상관 ≥ 0.5.
