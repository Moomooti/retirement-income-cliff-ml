사전 등록 – 추가 실험 E1 · E2 · E4  (작성 2026-11-04 09:40 KST, 실행 전)
결과를 본 뒤 정의·경계·지표·판정 규칙을 바꾸지 않는다. 결과는 성공·실패와 무관하게 모두 보고한다.

[E1] 노후 계산의 2차 검진 (국민노후보장패널)
- 대상: t 시점 50~69세, 필요 최소 노후생활비 응답이 있는 사람(계산 가능자). 계산상 괜찮음 = 충족률(월 가처분소득 ÷ 연도·가구유형별 필요 최소생활비 중위값) ≥ 1.
- 정답: 필요생활비 기준선으로 t+2·t+3·t+4 중 2번 이상 미만(격년 조사라 t+2·t+4 둘 다 미만).
- 시험: 4년 결과가 관측되는 최근 2개 기준 차수. 학습: 결과가 시험 시작 전에 끝나는 행.
- 모델: 계산 가능자 전체로 학습한 LightGBM + 로지스틱 순위 평균(v3 최종 모델과 같은 방식).
- 위험 구간 경계: 학습셋의 사람 단위 5겹 교차 예측(OOF) 점수 분위로만 정함. 낮음 = 하위 50%, 중간 = 50~80%, 높음 = 상위 20%.
- 산출: 계산(괜찮음/부족) × ML 위험(높음/중간/낮음) 표의 인원과 실제 반복 부족률(95% Wilson CI). 계산상 괜찮음 안에서 충족률 AUC vs ML AUC(DeLong).
- 성공 판정: 계산상 괜찮음 집단 안에서 실제 부족률이 낮음 < 중간 < 높음 순서이고, 높음과 낮음의 95% CI가 겹치지 않는다.

[E2] 일 전환 정답 – 봉인 시험 (6개 패널)
- T1 그만둠: t 시점 50~69세 취업자 중 t+2 조사에서 미취업이면 1.
- T2 재취업: t 시점 50~69세 미취업자 중 t+2 조사에서 취업이면 1.
- 시험: 기존 v1과 같은 최근 2개 기준 차수(TEST_YEARS). 학습: 기준연도 ≤ 시험 시작 − 2.
- 입력: 공통 입력 + 조사별 추가 입력(v1과 같은 규칙).
- 비교: ① 계산기형 = 나이 + 지금 소득비 로지스틱 ② 같은 입력 로지스틱 ③ LightGBM(학습구간 마지막 2개 연도로 격자 4개·반복 수 선택).
- 주판정: LightGBM − 계산기형 AUC 차이(DeLong). 성공 = 계산 가능한 조사(시험 양성·음성 각 20명 이상) 중 80% 이상에서 CI 하한 > 0. T1, T2 각각 판정.
- 보조: LightGBM − 같은 입력 로지스틱, 6개 결합 랜덤효과.

[E4] 확률 보정 개선 (v3 과제 5개: 복지·재정·국민노후(가처분)·국민노후(필요생활비)·노동)
- 모델: v3에서 튜닝된 LightGBM 설정 그대로 학습셋 전체로 재적합.
- 방법: A 원 확률 / B 학습구간 마지막 2개 연도 Platt(기존) / C 학습셋 사람 단위 5겹 교차 예측 Platt(신규).
- 지표: ECE(10분위), |평균 예측 − 실제|, Brier.
- 채택 판정: C의 ECE가 5개 중 4개 이상 과제에서 세 방법 중 가장 작고, 어느 과제에서도 A보다 ECE가 1%p 넘게 나쁘지 않으면 C 채택. 아니면 기존 방식 유지하고 실패로 보고.

[E1b] 2차 검진 – E1 설계 실수 보완 (작성 2026-11-04 09:46 KST)
- 설계 실수: E1은 위험 구간 경계를 계산 가능자 전체(계산상 괜찮음 + 부족)로 정해, 계산상 괜찮은 집단의 '높음'이 10명뿐이었다. 서비스는 계산상 괜찮은 사람 안에서 우선순위를 정하므로 경계를 그 집단 기준으로 다시 정의한다.
- 판정은 처음 채점하는 두 시점(O1·O2)으로 하고, E1과 같은 시험셋(O3)은 참고로 함께 보고한다.
- 대상: 계산상 괜찮음(충족률 ≥ 1)만. 정답은 E1과 같음.
- 모델: 계산상 괜찮은 학습행으로만 학습한 LightGBM + 로지스틱(학습 OOF 백분위 평균).
- 우선순위 비교: 상담 여력 상위 10%·20% 인원을 ① 충족률 낮은 순 ② ML 위험 순으로 골랐을 때 찾은 실제 반복 부족자 수.
- 구간: 학습셋(계산상 괜찮음) OOF 점수 분위로 상위 10% / 10~30% / 나머지 70%.
- 시험 시점(롤링): O1 기준연도 2013·2015(학습 ≤ 2009), O2 2015·2017(학습 ≤ 2011) = 처음 채점, O3 2017·2019(학습 ≤ 2013) = 이미 본 시험셋(사후 재정의로 표시).
- 성공: 3개 시점 모두 ML이 충족률보다 더 많이 찾고(10%·20% 각각), 3개 시점 합친 사람 단위 부트스트랩(1,000회) 차이(20% 기준)의 95% 하한 > 0.
- 구간 설명 가능: 3개 시점 모두 상위 10% > 10~30% > 나머지 순서.
